Project case study

Heart Disease Prediction using Machine Learning

Problem

The project explored how patient attributes can be used to identify patterns associated with heart disease. The focus was on analysing clinical variables, understanding relationships in the data, and evaluating machine learning models for classification.

Solution

I carried out exploratory data analysis, prepared the dataset for modelling, built multiple classification models, and evaluated model performance using appropriate metrics. Cross-validation and hyperparameter tuning were used to compare model reliability.

Outcome

The project helped identify the most useful clinical factors in the dataset and compare which modelling approach produced the most reliable performance. The final analysis focused on interpretability, model evaluation, and communicating results clearly.

Skills demonstrated

Python, Pandas, exploratory data analysis, classification, model evaluation, cross-validation, hyperparameter tuning, statistical analysis, data visualisation, and technical reporting.
